# TrafficTracer Complete 1.0.28

Linux x86-64 validation build on Ubuntu 24.04 LTS.

This release adds a versioned, redacted runtime proxy-semantics contract. The
Mihomo core exports configured and effective behavior for Shadowsocks, VLESS,
Hysteria2, Trojan, VMess, and AnyTLS through a closed allowlist. Credentials,
server endpoints, node names, SNI, Host values, paths, user identifiers, and
certificate material are excluded. Unknown enum values are marked
`unsupported` without reflecting their original text.

Every adapter receives a configuration generation, runtime instance ID,
snapshot ID, and behavior fingerprint. Mihomo attaches the exact reference to
proxy dial, logical-carrier binding, and carrier lifecycle events. TrafficTracer
preserves these references in flow and connection artifacts, while capture
start/end snapshots are used only to detect configuration, adapter, or binary
drift. Shared carrier reuse remains explicit rather than being converted into
false one-to-one flow ownership.

Each scoped Session stores a full `proxy-semantics.json` artifact and a compact
capture/analysis summary. The UI displays verification state, protocol,
coverage, adapter instance, configuration generation, and snapshot reference.
The controller lookup uses a JSON request body so private node names do not
appear in request URLs or URL-based access logs.

Build evidence includes the running executable SHA-256, Git revision and dirty
state, tracked-source digest, dependency-lock digest, and build-manifest digest.
The Deb bundle version is `2.5.2+traffictracer.1.0.28`, allowing an in-place
upgrade from 1.0.27. Packages do not include personal proxy profiles,
credentials, browser profiles, captures, or the local `Yu_VPS` configuration.
Locally built packages are unsigned unless a Tauri signing key is explicitly
provided.
