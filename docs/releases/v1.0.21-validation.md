## Blocking source-distribution finding

The tracked legacy `mihomo-configs/config.yaml` contains 71 proxy entries with
nonempty credential fields (55 UUID fields and 16 password fields). No values
are reproduced here. The tracked cache is also user runtime state.

The package secret audit excludes these files from binaries, but that does not
make the repository tree safe for a GitHub-generated source archive. Do not
publish a new tag at the original binary commit or upload an unfiltered source
archive. First preserve local configuration while removing runtime configuration
and cache from version tracking, then rebuild and audit a sanitized source
revision and publish matching provenance. Never falsify COMPONENTS to claim old
binaries were built from the sanitized commit.

Previously pushed history may still contain the credentials. Credential
rotation and any history rewrite require the owner's coordination; removing a
file from the new tree does not erase historical exposure.
