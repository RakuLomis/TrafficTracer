# TrafficTracer Complete 1.0.19

Prepared on 2026-09-05 for Linux x86-64.

## Page activity correctness

- Classify top-level document navigation independently from iframe and auxiliary request failures.
- Preserve requested URL, final URL, HTTP status chain, final status, timeout recovery, and HTTP-error recovery evidence.
- Report final top-level 4xx/5xx responses as application failures without invalidating capture or flow-correlation integrity.
- Summarize unrecovered Script, Stylesheet, and Font network or HTTP failures as resource health.
- Combine generic navigation, resource health, and optional playback evidence into a single backward-compatible activity outcome.

## Retry and UI

- Extend the one-attempt bounded application retry to classified transient page-load and critical-resource failures.
- Keep deterministic HTTP 4xx responses, recovered navigation, and short-but-positive playback non-retryable.
- Display persistent Activity state, final HTTP status, reason, and final URL in Session and Pipeline views.
- Preserve legacy scenario-only Sessions and treat unavailable CDP evidence as not applicable.

## Compatibility

TrafficTracer Complete 1.0.19 keeps Worker API 2, Job schema 3, Batch manifest 2,
Session manifest 2, Pipeline manifest 6, and Mihomo tracing API 1.

The Debian bundle version is `2.5.2+traffictracer.1.0.19`, preserving the
existing Clash Verge package identity and application data directory.

## Upgrade

~~~bash
cd /path/to/traffictracer-complete-v1.0.19-linux-x86_64
sha256sum -c SHA256SUMS
sudo apt install ./TrafficTracer-Complete_1.0.19_linux_x86_64.deb
~~~

Exit the currently running UI normally before launching the installed version.
Building and verifying the package does not stop the running application.
