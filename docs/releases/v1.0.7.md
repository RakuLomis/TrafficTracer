# TrafficTracer Complete 1.0.7

Released on 2026-08-22 for Linux x86-64.

## Added

- Running serial Capture Groups can be interrupted cooperatively from the UI without stopping Clash Verge or Mihomo.
- Completed targets remain intact, later targets do not start, and Resume retries the interrupted URL with a new Session in the same timestamped group.
- Capture Group history is scoped to the selected Session Output Directory and requires explicit selection for completed, failed, or interrupted groups.

## Fixed

- Failed and interrupted historical groups are no longer selected automatically as if they were the current capture.
- Interruption intent is propagated consistently through the TypeScript, Tauri/Rust, Worker, Job, batch, and Session layers.
- Interrupted Sessions remain inspectable and are not reported as corrupt solely because the capture stopped intentionally.

## Validation

- TrafficTracer Worker, batch recovery, Session indexing, and component-lock tests pass.
- Clash Verge TypeScript checks, UI tests, and TrafficTracer Rust protocol tests pass.
- The embedded Mihomo and Clash Verge component revisions match `complete/components.lock.yaml`.

## Upgrade

The Debian bundle version is `2.5.2+traffictracer.1.0.7`, so package managers treat it as newer than 1.0.6 while preserving the existing Clash Verge data directory.

```bash
sudo apt install ./TrafficTracer-Complete_1.0.7_linux_x86_64.deb
```

Building the package does not stop the running application. Exit the existing UI normally in a maintenance window before installing or launching the new version.
