# TrafficTracer Complete 1.0.18

Prepared on 2026-09-04 for Linux x86-64.

## Correctness

- Fold bounded Mihomo carrier lifecycle events into every matching logical flow before publishing connection artifacts.
- Preserve late Hysteria2 path updates by `(carrier_id, generation)` and retain explicit match evidence.
- Retry physical PCAP extraction by a local UDP socket only when that endpoint belongs to exactly one carrier in the Session.
- Keep ambiguous carrier endpoints unresolved instead of attributing protocol- or node-wide traffic to a page.

## Pipeline stability

- Materialize queued Profile/node candidates before capture and bind each repetition to a canonical semantic runtime fingerprint.
- Persist Profile activation, configuration drift, candidate circuit-breaker, and repeated-run quality evidence in pipeline manifest schema 6.
- Enable the bounded classified playback retry by default in the UI and show its frozen policy and used count in Capture Group progress.

## Compatibility

TrafficTracer Complete 1.0.18 keeps Worker API 2, Job schema 3, Batch manifest 2, Session manifest 2, and Mihomo tracing API 1. Pipeline manifest schemas 1-5 remain readable.

The Debian bundle version is `2.5.2+traffictracer.1.0.18`, preserving the existing Clash Verge package identity and application data directory.

## Upgrade

~~~bash
cd /path/to/traffictracer-complete-v1.0.18-linux-x86_64
sha256sum -c SHA256SUMS
sudo apt install ./TrafficTracer-Complete_1.0.18_linux_x86_64.deb
~~~

Exit the currently running UI normally before launching the installed version. Building and verifying the package does not stop the running application.
