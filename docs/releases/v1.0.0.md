# TrafficTracer Complete 1.0.0

Release date: 2026-08-13

TrafficTracer Complete 1.0.0 is the first Linux x86-64 release that pins and packages the TrafficTracer Worker, the TrafficTracer-aware Mihomo core, and the Clash Verge UI as one tested product.

## Artifacts

- `TrafficTracer-Complete_1.0.0_linux_x86_64.deb`
- `TrafficTracer-Complete_1.0.0_linux_x86_64.AppImage`
- `SHA256SUMS`, `VERSION`, `COMPONENTS`, `SBOM.cdx.json`, `METADATA.sha256`, and `RELEASE-AUDIT.json`

The release directory is `dist/packages/traffictracer-complete-v1.0.0-linux-x86_64/`.

## Verified baseline

- 21/21 page Sessions passed integrity and network-health checks in the final expanded capture.
- 624/624 observed transports were matched.
- Page-attributed flows comprised 461 proxied, 154 rejected, and 9 local flows, with no unexpected missing egress.
- All 46 proxied page flows used the selected proxy chain in that acceptance run.
- Time evidence was available for 624/624 transports.

These figures describe the recorded acceptance dataset, not a guarantee that every future site, browser behavior, or proxy protocol will produce the same distribution.

## Install

From the release directory:

```bash
sha256sum -c SHA256SUMS
sudo apt install ./TrafficTracer-Complete_1.0.0_linux_x86_64.deb
```

Installing the Deb replaces the existing Clash Verge package files but preserves user configuration. Exit the old UI normally during a network maintenance window before starting the new version. Do not force-stop the currently running core merely to build or verify these artifacts.

## Known boundaries

- Linux x86-64 is the only 1.0.0 release target.
- Browser-internal, cache-only, or Service Worker-only activity can be conservatively marked non-network or degraded rather than fabricated as a flow.
- Shared multiplexed proxy transports are explicitly non-one-to-one and retain that warning.
- An unsigned build is not an updater-signed release; verify the supplied SHA-256 and audit metadata.
