# TrafficTracer Complete 1.0.21

Publication is pending the [release validation record](v1.0.21-validation.md),
including source sanitization and a matching rebuild. No release tag has been
created by this preparation.

This release isolates pipeline profile commits from native UI notifications,
coalesces pending refreshes, and fixes asynchronous frontend listener cleanup.
An independent heartbeat detects activation without progress for over 90 seconds,
records `pipeline-stall.json`, and requests cooperative interruption without
killing the core or starting a competing activation.

Capture-only Session totals and pending analysis progress are now reported
independently of analysis quality. A 270-cell recovery regression preserves the
first 35 captured Sessions and resumes at cell 36.

See the [repair and acceptance record](../complete/profile-activation-hang-repair.md)
for evidence and limitations. Native tray rebuilding is omitted for pipeline
switches; labels can lag until a normal manual refresh. The resumed detailed
experiment completed all 270 planned cells with analysis and packet extraction.
Its first 35 final Sessions were retained from 1.0.20; the remaining 235 final
Sessions and five superseded retry Sessions were captured with 1.0.21. This is
evidence for recovery and sustained execution, not proof that all native hangs
are impossible or that a clean-install environment has been validated.

Protocol/schema versions are unchanged. The Debian bundle version is
`2.5.2+traffictracer.1.0.21`. These Linux x86-64 packages are unsigned and were
built on Ubuntu 24.04 LTS. Windows packages are not included.

## Known limitations

- A fixed capture window does not guarantee 25 seconds of YouTube primary
  playback. Playback observations and failures remain explicit in each result.
- Some sites return access-denied or anti-abuse pages. Successful capture and
  analysis do not imply successful application activity.
- Five requests in the detailed experiment retained ambiguous transport
  attribution; all were redirected Zhihu favicons. Ambiguity is not forced into
  a one-to-one match.
- Hysteria2 outer carriers can be shared. Do not treat repeated references to
  one carrier PCAP as independent per-flow packet samples.
- Profile/node selection is verified against the core. During pipeline switches,
  tray labels may be stale because native tray rebuilding is deliberately omitted
  from the critical path. A stale label alone does not indicate a failed switch.
