# TrafficTracer Complete 1.0.26

Linux x86-64 validation build on Ubuntu 24.04 LTS.

This release separates local capture health from remote application evidence.
Expected loopback probes and browser-policy blocks remain auditable but no
longer inflate the remote critical-resource failure denominator. A main
document that recovers from an intermediate HTTP error to a final 2xx response
is reported as passed with explicit recovery evidence.

Analysis summaries now expose a dedicated local-runtime quality plane for
Chrome lifecycle, packet-capture coverage, and bounded Mihomo trace evidence.
Application issues preserve their observed origin and retry eligibility, while
ambiguous request-to-transport attribution remains unresolved unless unique
evidence selects one candidate.

The Pipeline manifest advances to schema version 8. Older manifests remain
readable. The Deb bundle version is `2.5.2+traffictracer.1.0.26`, allowing an
in-place upgrade from 1.0.25. Personal proxy profiles, credentials, browser
profiles, captured datasets, and user configuration are excluded from the
packages.

Source validation passed 732 Python tests, 195 Rust library tests, TypeScript
type checking, ESLint, focused lifecycle tests, and replay against the latest
64-target capture. Package-side component, checksum, and extracted-bundle
checks are required before installation.

See [local quality and failure provenance](../complete/local-quality-provenance.md)
for the evidence boundary and compatibility details.
