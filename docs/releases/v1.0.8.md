# TrafficTracer Complete 1.0.8

Released on 2026-08-23 for Linux x86-64.

## Added

- A Hysteria2-aware, protocol-neutral physical carrier model with stable
  identity, generation, path updates, and logical-flow bindings.
- Strict single-protocol capture groups with optional expected protocol and a
  non-blocking observation mode.
- Carrier binding, proxy protocol, and inbound consistency summaries in
  analysis results and the desktop UI.

## Fixed

- Reused Hysteria2 TCP streams and UDP associations now retain the physical
  QUIC/UDP carrier evidence created by an earlier logical flow.
- Port hopping keeps one carrier identity and records every observed path.
- Full packet splitting stores one shared encrypted carrier artifact and lets
  bound logical connections reference it without claiming exclusive bytes.
- Resume retains the protocol invariant frozen when the Capture Group started.

## Compatibility

The three components are a pinned set. Do not combine the 1.0.8 Worker or UI
with an older Mihomo TrafficTracer core because the new diagnostics require the
carrier lifecycle, logical binding, multi-path, and protocol snapshot
capabilities.

The Debian bundle version is 2.5.2+traffictracer.1.0.8, so package managers
treat it as newer than 1.0.7 while preserving the Clash Verge application
identity and user data directory.

## Upgrade

    sudo apt install ./TrafficTracer-Complete_1.0.8_linux_x86_64.deb

Building the package does not stop the running application. Exit the existing UI
normally during a maintenance window before installing or launching the new
version.
