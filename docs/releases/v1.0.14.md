# TrafficTracer Complete 1.0.14

Released on 2026-09-01 for Linux x86-64.

## Added

- Added a durable Profile/node capture pipeline that runs one selected `sites.yaml` target set through an ordered queue of `(Profile, selector, node)` candidates.
- Added pipeline progress persistence, output-root history selection, interrupt, cancel, and checkpoint-aware resume controls.
- Added pipeline, run, Profile, selector, and node provenance to Batch manifests and every child Session capture context.
- Added resolved proxy-chain, expected leaf protocol, and bounded Mihomo trace protocol observations to pipeline manifests.

## Safety and recovery

- Holds one owner-scoped capture lock across the entire pipeline and authorizes only the supervisor to switch Profiles or start inner Batches.
- Reads back every selector transition, closes old Mihomo connections, and waits for quiescence before starting the next serial Capture Group.
- Restores the original Profile and selector state on completion, interruption, cancellation, and failure paths.
- Recovers a stale running supervisor as an interrupted pipeline without discarding its inner Batch checkpoint. Resume rejects changed target configuration and changed Profile fingerprints instead of silently substituting state.

## Compatibility

TrafficTracer Complete 1.0.14 keeps Worker API 2, Job schema 2, Batch manifest schema 1, Session manifest schema 2, and Mihomo tracing API 1. The new job and Batch provenance objects are optional, so standalone and pre-pipeline capture requests remain compatible.

The Debian bundle version is `2.5.2+traffictracer.1.0.14`, so package managers treat it as newer than 1.0.13 while preserving the existing Clash Verge package identity and application data directory.

## Upgrade

```bash
cd /path/to/traffictracer-complete-v1.0.14-linux-x86_64
sha256sum -c SHA256SUMS
sudo apt install ./TrafficTracer-Complete_1.0.14_linux_x86_64.deb
```

Exit the currently running UI normally before launching the installed version. Building and verifying the package does not stop the running application.
