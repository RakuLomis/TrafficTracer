# TrafficTracer Complete 1.0.12

Released on 2026-08-26 for Linux x86-64.

## Fixed

- Home core queries now deserialize Mihomo configurations that legitimately omit an empty TUIC `ech-key` field.
- The Rust and JavaScript Mihomo API plugins are pinned to the same compatible upstream revision.
- Persisted lowercase log-level preferences are translated at the WebSocket boundary for the updated plugin API.
- Traffic graph samples remain compatible with the updated cumulative traffic model without fabricating unused totals.

## Compatibility

TrafficTracer Complete 1.0.12 pins the Worker and Mihomo core from 1.0.11 while
updating the Clash Verge UI to commit
`15c09b2f618226c10fa08941bdb542a6ae4e8331`.

The Debian bundle version is `2.5.2+traffictracer.1.0.12`, so package managers
treat it as newer than 1.0.11 while preserving the existing Clash Verge package
identity and application data directory.

## Upgrade

```bash
cd /path/to/traffictracer-complete-v1.0.12-linux-x86_64
sha256sum -c SHA256SUMS
sudo apt install ./TrafficTracer-Complete_1.0.12_linux_x86_64.deb
```

Exit the currently running UI normally before launching the installed version.
Building and verifying the package does not stop the running application.
