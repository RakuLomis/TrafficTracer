# TrafficTracer Complete 1.0.11

Released on 2026-08-26 for Linux x86-64.

## Fixed

- Home now recovers its Mihomo-backed data after sidecar-to-service controller
  transitions instead of retaining a transient startup error.
- Proxy Mode and Clash Info refresh after the selected controller passes a real
  API probe.
- Failed core queries retry at a bounded interval and stop polling after
  recovery.
- Clash Info shows an explicit loading or communication-error state with a
  manual retry action instead of rendering an empty card.
- Core refresh events now cover rules and rule providers as well as proxies,
  configuration, version, and proxy providers.

## Compatibility

TrafficTracer Complete 1.0.11 pins the Worker and Mihomo core from 1.0.10 while
updating the Clash Verge UI to commit
`b16fc278098b8a1fac91f8278a2d33495c8ac35a`.

The Debian bundle version is `2.5.2+traffictracer.1.0.11`, so package managers
treat it as newer than 1.0.10 while preserving the existing Clash Verge package
identity and application data directory.

## Upgrade

```bash
cd /path/to/traffictracer-complete-v1.0.11-linux-x86_64
sha256sum -c SHA256SUMS
sudo apt install ./TrafficTracer-Complete_1.0.11_linux_x86_64.deb
```

Exit the currently running UI normally before launching the installed version.
Building and verifying the package does not stop the running application.
