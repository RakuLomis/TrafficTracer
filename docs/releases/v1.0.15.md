# TrafficTracer Complete 1.0.15

Released on 2026-09-02 for Linux x86-64.

## Fixed

- Serialized Pipeline Worker workspace switching with the owner-scoped capture lock so stale environment diagnostics cannot switch a run back to the primary output directory.
- Paused frontend environment re-diagnosis while a Pipeline is starting or active.
- Restored each run Session root before resuming an interrupted inner Capture Group.
- Replaced oversized Worker ready notifications with bounded recovery summaries while retaining the complete report in the backend.

## Safety and recovery

- Holds one owner-scoped capture lock across the entire pipeline and authorizes only the supervisor to switch Profiles or start inner Batches.
- Reads back every selector transition, closes old Mihomo connections, and waits for quiescence before starting the next serial Capture Group.
- Restores the original Profile and selector state on completion, interruption, cancellation, and failure paths.
- Recovers a stale running supervisor as an interrupted pipeline without discarding its inner Batch checkpoint. Resume rejects changed target configuration and changed Profile fingerprints instead of silently substituting state.

## Compatibility

TrafficTracer Complete 1.0.15 keeps Worker API 2, Job schema 2, Batch manifest schema 1, Session manifest schema 2, and Mihomo tracing API 1. Worker API and capture contracts remain unchanged from 1.0.14; this release fixes orchestration and frontend event delivery without changing dataset schemas.

The Debian bundle version is `2.5.2+traffictracer.1.0.15`, so package managers treat it as newer than 1.0.14 while preserving the existing Clash Verge package identity and application data directory.

## Upgrade

```bash
cd /path/to/traffictracer-complete-v1.0.15-linux-x86_64
sha256sum -c SHA256SUMS
sudo apt install ./TrafficTracer-Complete_1.0.15_linux_x86_64.deb
```

Exit the currently running UI normally before launching the installed version. Building and verifying the package does not stop the running application.
