# TrafficTracer Complete 1.0.3

Released on 2026-08-15 for Linux x86-64.

## Fixed

- Home **Current Node** delay checks now update from `testing` to the final
  latency or error without navigating to the Proxies page.
- Per-proxy and per-group delay updates now support multiple UI subscribers
  without one component replacing another component's listener.
- Home waits for both per-node and group delay checks to settle before the
  final proxy-data refresh.
- Listener cleanup now removes only the owning component's subscription.

## Validation

- TypeScript type checking and targeted ESLint checks pass.
- All 27 frontend tests pass, including new DelayManager subscription tests.
- All 13 Node-side packaging and service-layout tests pass.
- The production Web bundle builds successfully.

## Upgrade

The Debian bundle version is `2.5.2+traffictracer.1.0.3`, so it upgrades the
1.0.2 package in place while preserving the existing Clash Verge data
directory.

```bash
sudo apt install ./TrafficTracer-Complete_1.0.3_linux_x86_64.deb
```

Exit the currently running UI normally before launching the newly installed
version. Building and installing the package does not require terminating the
existing process in advance.
