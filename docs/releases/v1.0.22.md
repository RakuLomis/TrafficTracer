# TrafficTracer Complete 1.0.22

Linux x86-64 validation build, prepared on Ubuntu 24.04 LTS.

This update bounds Worker-to-UI progress delivery, archives non-progress
notifications before bounded presentation, and restores displayed state after
desktop unlock. It also includes batched packet-analysis and NetLog fast paths,
subprocess health checks, Worker lifecycle safeguards and result pagination.

The isolated native test recovered after 62 minutes 48 seconds of locking in a
90-minute observation. The user confirmed normal interaction after unlocking.
The original diagnostic report is retained, not relabelled as a clean foreground
test pass. See [the validation record](../complete/bounded-ui-delivery-plan.md).
Real capture, long-running analysis and Resume validation remain required.

The Deb package version is `2.5.2+traffictracer.1.0.22`, higher than 1.0.21.
Quit the previous UI normally before launching the new version. Installation
does not include personal proxy profiles, subscription credentials, browser
profiles or capture datasets. Existing user configuration is not replaced by
example site files. Locally built packages are unsigned unless explicitly stated.

No GitHub release publication is implied by this build. See the
[release checklist](../release-checklist.md) for public-release acceptance.
