# TrafficTracer Complete 1.0.5

Released on 2026-08-19 for Linux x86-64.

## Fixed

- Resume transitions continue polling until the Worker exposes the new running attempt, preventing stale failed-child state from masking an active resumed batch.
- Batch status selection now prefers the newest manifest revision and reports continued capture progress consistently between the Worker and UI.
- Correlation preserves normalized pre-proxy tuples across resumed analysis and includes only bounded, causally related Mihomo events after a trace barrier.
- Explicit reject, local endpoint, and failure-before-socket outcomes remain distinguishable from genuinely missing post-proxy flow evidence.

## Validation

- All 64 targets in the expanded site catalog completed in a full capture.
- All 11,123 eligible browser network requests were attributed, and all 1,797 page transport connections were correlated without ambiguity.
- YouTube primary playback exceeded the configured 25-second goal; all observed Googlevideo media connections were associated with proxy-side pre/post flow tuples.

## Upgrade

The Debian bundle version is `2.5.2+traffictracer.1.0.5`, so package managers treat it as newer than 1.0.4 while preserving the existing Clash Verge data directory.

```bash
sudo apt install ./TrafficTracer-Complete_1.0.5_linux_x86_64.deb
```

Exit the currently running UI normally before launching the newly installed version.
