# TrafficTracer Complete 1.0.2

Release date: 2026-08-15

TrafficTracer Complete 1.0.2 is a Linux x86-64 playback-correctness release.
It keeps the 1.0 Worker, Job, Session, flow, and analysis contracts while making
advancing primary video—not ad presence or a reported player state—the primary
YouTube scenario result.

## Fixes

- YouTube observation JavaScript is read-only and limits Play and Skip controls
  to the active player and ad module.
- Play and Skip interactions use CDP mouse movement, press, and release events.
- Primary content requires consecutive non-ad media-time advances; a stalled
  player that reports a playing state is not accepted.
- The fixed capture window is never shortened or extended. Unskippable ads may
  finish normally, and a run with no served ad is valid.
- Analysis and UI output distinguish primary observed, primary below target, no
  primary, no ad, no Skip control, Skip attempted, and Skip confirmed.

## Diagnostics

The standalone `scripts/test-youtube-ad-skip.py` tool uses a fresh temporary
Chrome profile for every case and closes only the browser process it launches.
It is a diagnostic tool; the desktop capture path remains authoritative.

## Upgrade

The Debian bundle version is `2.5.2+traffictracer.1.0.2`, so package managers
recognize it as newer than `2.5.2+traffictracer.1.0.1`.

```bash
sudo apt install ./TrafficTracer-Complete_1.0.2_linux_x86_64.deb
```

Exit an older UI normally before installing when practical. Building and
verifying this release does not require stopping a running Clash Verge or
Mihomo process. Packages are verified but unsigned when no Tauri updater signing
key is configured; verify `SHA256SUMS` before installation.
