# TrafficTracer Complete 1.0.4

Released on 2026-08-18 for Linux x86-64.

## Fixed

- CDP requests that reuse one Chrome request ID across redirects are now stored
  as separate request occurrences with stable IDs, redirect indices, URLs,
  response metadata, and completion metadata.
- Legacy captures receive deterministic occurrence metadata during offline
  reanalysis, without changing their raw evidence.
- Consistency validation distinguishes valid redirect chains from true
  duplicate occurrence identifiers.
- Resuming an interrupted serial batch now uses the same timestamp batch
  directory, skips completed targets, resets failed targets for retry, and then
  continues with later pending targets.
- A failed target no longer aborts a UI-created or resumed broad site batch by
  default; the batch completes with explicit per-target errors.

## Site catalog

The default `sites.yaml` is normalized and expanded to cover static pages,
portals, maps, developer sites, content platforms, news, commerce, media,
real-time applications, and network-oriented pages.

## Validation

- All 522 TrafficTracer Python tests pass.
- Targeted Clash Verge batch UI tests and TypeScript type checking pass.
- A real captured Stack Overflow redirect session reanalyzes successfully and
  preserves both its 307-to-403 and 302-to-200 redirect occurrences.

## Upgrade

The Debian bundle version is `2.5.2+traffictracer.1.0.4`, so it upgrades the
1.0.3 package in place while preserving the existing Clash Verge data
directory.

```bash
sudo apt install ./TrafficTracer-Complete_1.0.4_linux_x86_64.deb
```

Exit the currently running UI normally before launching the newly installed
version. Building and installing the package does not require terminating the
existing process in advance.
