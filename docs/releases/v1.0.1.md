# TrafficTracer Complete 1.0.1

Release date: 2026-08-14

TrafficTracer Complete 1.0.1 is a Linux x86-64 reliability release. It keeps
the 1.0 data contracts and flow-correlation semantics while improving bounded
YouTube playback observation and TrafficTracer UI recovery.

## Fixes

- YouTube playback observation uses the player API and the active visible video
  element, waits five seconds before controlled Skip or Play interaction, and
  never extends the configured 35-second capture window.
- Playback diagnostics contain bounded state counters and no page text, signed
  media URLs, or browsing credentials.
- Analysis integrity, network outcome, and playback scenario outcome are
  reported independently.
- Terminal batch state is not restored as active after restart.
- Missing packet-split Jobs stop polling and clear their persisted identifier.
- Packet-split preview is disabled while a capture batch is active.
- A TrafficTracer page heartbeat records UI stalls. The tray can reload only the
  user interface without restarting Mihomo or intentionally cancelling capture.

## Upgrade

The Debian bundle version is 2.5.2+traffictracer.1.0.1, so package managers
recognize it as newer than 2.5.2+traffictracer.1.0.0.

    sudo apt install ./TrafficTracer-Complete_1.0.1_linux_x86_64.deb

Exit an older UI normally before installing when practical. If only the
TrafficTracer WebView becomes unresponsive after upgrade, use **Reload User
Interface** from the tray instead of force-closing the application.
